# うつわのはなし(仮) ホームページ

器のEC販売に向けた、作家紹介・ブランドコンセプト発信用のホームページです。
シンプルなHTML/CSS/JSのみで構成しており、ビルド作業なしでGitHub Pagesにそのまま公開できます。

## ファイル構成

```
site/
├── index.html          トップページ(読みもの・商品ページ混在の雑誌型フィード)
├── products.html        新着商品ページ(STORES/BASEの販売ボタンを設置)
├── concept.html          読みもの記事(コンセプト)
├── news.html            お知らせ一覧
├── artists/
│   ├── index.html       読みもの一覧
│   ├── artist-01.html   読みもの記事(山田陶子・サンプル)
│   └── artist-02.html   読みもの記事(佐藤一輝・サンプル)
├── css/style.css        共通スタイル(モノトーン基調)
├── js/main.js           (現状は空。将来的なJS処理用)
└── images/              画像置き場(現状は空)
```

サイト構成は「北欧、暮らしの道具店」(hokuohkurashi.com) を参考に、読みもの記事と商品ページを混在させた雑誌型フィードにしています。トンマナ(配色・フォント)は nudevintage.thebase.in を参考にしたモノトーン基調です。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する(例: `my-utsuwa-shop`)。
2. このフォルダの中身(index.htmlやcssフォルダなど)をリポジトリ直下にすべてアップロードする。
3. リポジトリの Settings → Pages を開く。
4. 「Branch」で公開したいブランチ(通常 `main`)と `/ (root)` を選択して保存する。
5. 数分待つと、`https://ユーザー名.github.io/リポジトリ名/` でサイトが公開される。

独自ドメインを取得したら、同じPages設定画面の「Custom domain」欄にドメインを入力すれば切り替えられます。取得までは上記のgithub.ioのURLで運用して問題ありません。

## 作家(読みもの記事)を追加する方法

1. `artists/artist-01.html` をコピーして `artists/artist-03.html` のような名前で保存する。
2. 中身の名前・経歴・商品情報などを書き換える。
3. `artists/index.html` の一覧に、新しい記事へのカード(`<div class="feed-card">...`のブロック)を追加する。
4. トップページ(`index.html`)にも載せたい場合は、同じ要領でカードを追加する。

作家数が今後かなり多くなる場合(数十件以上)は、今のように1人1ファイルで手作業管理するより、データを一つのファイル(JSONなど)にまとめてJavaScriptで一覧を描画する方式や、Jekyll/Astroなどの静的サイトジェネレーターへの移行を検討した方が管理が楽になります。まずはこのシンプルな構成で始めて、負担が増えてきたタイミングで相談してください。

## お知らせを追加する方法

`news.html` 内の `<ul class="news-list">` の一番上に、既存の `<li class="news-item">` ブロックをコピーして貼り付け、日付と内容を書き換えてください。

## BASE・STORESとの連携について

BASEショップ(`https://yohenpottery.base.shop/`)のリンクを全ページに反映済みです。商品ごとの個別リンク(`/items/【商品ID】`の部分)は、それぞれの商品詳細ページのURLに書き換えてください。

新着商品ページ(`products.html`)には、STORESの販売ボタン(埋め込みコード)も設置しています。商品を追加する際は、STORESの管理画面で発行される埋め込みコードに差し替えてください。

### 商品ウィジェットの埋め込み(任意)

各読みもの記事の商品部分には、BASE公式のiframeウィジェットを設置できるようにしてあります。

```html
<iframe frameborder="0" height="220" width="160"
  src="【商品詳細ページのURL】/widget">
</iframe>
```

`src`の部分を実際の商品詳細ページURLに書き換えるだけで、商品の画像・価格つきのカードが表示されます。クリックするとBASEの商品ページに遷移し、そこで購入手続きを行う形になります(このウィジェット自体はリンクカードであり、サイト上で直接カートに入れることはできません)。BASE公式ヘルプ: https://help.thebase.in/hc/ja/articles/900000108823

### なぜこの方式にしたか

BASEには決済までを外部サイトに完全に埋め込む公式手段は用意されていません(非公式なフォーム送信によるカート追加は動作するとの情報もありますが、BASE非公式かつ仕様変更で壊れる可能性があるため推奨しません)。そのため、ホームページ側は「情報発信とBASE・STORESへの導線」に徹し、決済はBASE・STORESの信頼できるページで完結させる構成にしています。将来的に在庫連携や価格の自動反映まで行いたい場合は、BASEのAPIを使った専用の仕組みを別途検討する必要があります。

## 今後の検討事項

- ブランド名(現在は仮で「うつわのはなし」としています)が決まったら、全HTMLファイルの `<title>` タグ・ヘッダー・フッターの文字列を検索置換してください。
- 写真素材ができたら、`.card-image` や `.profile-photo`、`.feed-card-image` の「写真準備中」テキストを `<img>` タグに置き換えてください。
- 独自ドメイン取得後は、GitHub PagesのCustom domain設定と、必要に応じてBASE側の店舗情報(SNSリンクなど)も更新してください。
